# Abdul Mannan Portfolio

A modern and responsive full-stack developer portfolio built with **Next.js (App Router)**, **Tailwind CSS**, and **Framer Motion**.

## Features

- Clean, professional, minimal UI
- Fully responsive layout (mobile, tablet, desktop)
- Dark/light mode toggle with local persistence
- Smooth scrolling navigation with active section highlighting
- Animated sections and cards (Framer Motion)
- Reusable component architecture
- Contact form with frontend loading/success states
- SEO-ready metadata

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Production Build

```bash
npm run build
npm run start
```

## Deploy on Vercel

1. Push your project to GitHub.
2. Go to [Vercel](https://vercel.com/new) and import your repository.
3. Framework preset: **Next.js**.
4. Click **Deploy**.

No additional environment variables are required for this frontend-only portfolio.
